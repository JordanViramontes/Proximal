# Proximal 
Senior design project for CS179N (Graphics and Electronic Games) at UCR. Made in 10 weeks.

Wave-based arena first person shooter game where you attempt to survive against an increasingly difficult onslaught of angelic forces. You must cleverly use your arsenal of five weapons and our unique weapon leveling system to survive as long as possible. 

## Installation instructions
This process will allow you to play the developer version of the game with full access to all of the scripts, assets, scenes, etc. 

* Clone the repository somewhere on your machine. 
* Download Godot 4.4.1 for your machine from https://godotengine.org/download/archive/4.4.1-stable/
* Launch the Godot executable, and click **"Import"** at the top of the project manager window that opens.
* Locate the repository which you cloned earlier. Navigate to its root folder and click **"Select current folder"** at the bottom (there should be a file called project.godot in this folder).
* The project should open automatically. If it doesn't, it should now appear in the project manager and you can double click it to open it. 
* Once the project opens, press F5 or click the play button on the top right of the editor to run the game in debug mode.
* Hope you have fun playing around!
