# Proximal
### Wave based first person shooter game with slightly complex weapon mechanics.

Senior design project for CS179N in Spring 2025 at UC Riverside.

Made in the Godot game engine by Garett Hammerle, Jordan Viramontes, Kevin Wu, Thomas Nguyen, and Benedict Ignacio. 

## Installation Instructions
To open the game in the engine, download Godot 4.4.1 from https://godotengine.org/. Clone the repo somewhere. Then simply open up the repo with the engine, and press F5 or the play button in the top right!

If you don't want to download it, you can watch a gameplay video here: https://drive.google.com/drive/u/2/folders/1yfehUvhzRhcLl6DNtoLyjLeIYvL9c2s6
